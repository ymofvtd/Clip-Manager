# Destination and state specification

```text
┌───────────────────────────────────────────────────────────────┐
│ Clips Manager v…                                              │
├───────────────┬───────────────────────────────────────────────┤
│ Overview      │ Workspace title                               │
│ Archive       │ Configure | Review files (tools)               │
│ Batches       │ Preset selector / Apply / Save / Manage         │
│ Find & clean  │ Explicit folder roles and configuration        │
│ Rename        │ Scrollable fields or virtualized review        │
│ Activity      │ Persistent result / error / recovery details    │
│ Settings      │ Pinned Analyze / Review and run                │
├───────────────┴───────────────────────────────────────────────┤
│ Archive indicator │ current phase / elapsed │ Cancel │ Activity│
└───────────────────────────────────────────────────────────────┘
```

The default target is 1180×760. At compact widths the rail narrows, flow rows wrap, and configuration scrolls while command rows remain visible. Tool choice buttons preserve separate drafts; Configure and Review files separate long configuration from wide result tables. OS pickers, preset editors and exact final confirmations are focused dialogs.

| Destination | Configure / content | Empty / loading | Error / result |
| --- | --- | --- | --- |
| Overview | Current work, Archive health/pending/last verification, working-folder role, tracking roots, optional setup and next actions | Choose working folder; optional tracking/Archive; Skip setup | Persistent settings/drive attention text; Activity opens exact outcomes |
| Archive | Sources, destination, Run once/Watch continuously, Fast/Slow, advanced interval/settle/I/O | Stopped vs Watching; structured pending table; load catalog explicitly | Suspended/disconnected roots; retries and bounded log; verified count differs from pending |
| Batches / Prepare | Source, parent, selection scope, minutes, optional new-folder name | Analyze resolves c_ folder/new folder without creating it | Review each recycle/keeper, backup and move; starter/planned totals and transaction contract |
| Batches / Shuffle | Archive root and maximum minutes | Analyze lists pool, packs once, creates no folders | Exact before/after paths; oversized clip count; rollback explanation |
| Find & clean / Compare | A and B, recursion, overlap and all-Keep explanation | No complete matches differs from unreadable scope | Individual Keep/Recycle; hard links locked Keep; hidden selection count; exact keeper confirmation |
| Find & clean / Clean | One root, alphabetical keeper policy | Complete zero duplicates differs from incomplete scan | Proposed keepers/extras; partial scan blocks mutation; transactional recycle details |
| Find & clean / Identify | Reference, recursive search root, Inspect / Move / Recycle, destination | Scan with reference excluded | Exact match paths; fixed suffix destinations; reference/alias protection; incomplete scan blocks actions |
| Rename & shuffle | Three separate modes; appropriate number/padding/prefix/random length | Empty folder has no actionable mutation | Exact original→proposed mappings; refresh random preview is explicit; changed/collision guard errors |
| Activity | Bounded recent/current records, outcome filter, copy/log actions | No previous jobs; running record remains unfinished | Cancelled, issues, failed and interrupted are distinct; retained recovery paths are visible |
| Settings | General, Duration tracking, Presets, Updates, About | Independent roots and opt-in startup; preserve existing registration | Inline save/load failures, current/update states, saved defaults, diagnostics paths |

Annotated native evidence is in screenshots/. `duplicate-review-prototype.png` uses 10,000 generated rows; the same virtual control renders a 50,000-entry catalog. Legacy forms are covered by compatibility fixtures; a full baseline visual capture remains a manual audit item.
